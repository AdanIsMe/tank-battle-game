# Tank Battle Visualization Tool

A Pygame-based visualizer for Tank Battle game simulations.

## Quick Start

```bash
# Set up environment
python3 -m venv myenv
source myenv/bin/activate  # Linux/Mac
# myenv\Scripts\activate  # Windows

# Install requirements
pip install pygame

# Run visualizer
python viewer.py

# Exit environment
deactivate
```
